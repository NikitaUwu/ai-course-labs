Название: Научные подходы к извлечению данных из графиков
Тема диплома: Информационная система по извлечению и преобразованию числовых данных с графиков функций
Тип документа: предметная база знаний для RAG
Источники:
- ChartSense, Microsoft Research: https://www.microsoft.com/en-us/research/publication/chartsense-interactive-data-extraction-chart-images/
- Scatteract, arXiv: https://arxiv.org/abs/1704.06687
- ChartLine, Sensors 2024: https://www.mdpi.com/1424-8220/24/21/7015

ChartSense рассматривает извлечение данных из изображений диаграмм как интерактивную задачу. Система сначала определяет тип диаграммы с помощью классификатора, затем применяет алгоритмы извлечения, оптимизированные под конкретный тип графика. Этот подход полезен для дипломной работы: перед извлечением данных система должна понять, работает ли она с линейным графиком, scatter plot, bar chart или другим типом визуализации.

Scatteract посвящен автоматическому извлечению данных из scatter plot. Важная идея работы: для восстановления числовых значений недостаточно найти точки на изображении. Нужно также распознать компоненты графика, текстовые подписи и построить отображение из пиксельных координат в координаты графика. В работе используется сочетание компьютерного зрения, OCR и устойчивой регрессии для связи пикселей с числовой шкалой.

ChartLine фокусируется на автоматическом обнаружении и трассировке кривых на научных линейных графиках. В таких графиках часто встречаются сложные фоны, пересечения линий, сетка, шум, сжатие изображения, подписи и несколько серий данных. Работа подчеркивает, что извлечение исходных данных из линейного графика можно разделить на два этапа: выделение кривой на изображении и преобразование выделенной кривой в точки.

Для дипломной информационной системы из этих подходов следует архитектурный вывод: система должна быть модульной. Отдельные модули отвечают за загрузку изображения, классификацию типа графика, распознавание осей и подписей, калибровку, выделение кривой, восстановление точек, ручную проверку и экспорт результата. Такой подход позволяет постепенно улучшать алгоритмы, не переписывая весь продукт.

В рамках лабораторной работы RAG-база знаний может помогать пользователю понимать, какой метод применить к конкретному графику, почему результат может быть неточным и какие параметры обработки стоит изменить.
